How it works

1. Data
1,797 handwritten 8×8 grayscale digit images (0–9), pixel values scaled to 0–1.
2. Model
Softmax regression (multinomial logistic regression, scikit-learn). It learns one 64-pixel weight map per digit plus a bias — the weights literally look like the digits. 5-fold CV accuracy: 97.0%.
3. Browser
weights.json (10 weight vectors + 10 biases + sample digits) is shipped to the site; JavaScript downsamples your drawing to 8×8 and re-runs the exact same softmax math as sklearn's predict_proba.
4. Explainable
The prediction is just a weighted vote of pixels — no black box. Draw messily and watch the probability spread.
